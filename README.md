# La-pauta-studio
La Pauta Studio - El DAW de RD pa'l mundo. Inspirado en REAPER, con interfaz blanca, liviano como si fuera pa' un Pentium 3, que corre en cualquier PC de cartón. Crea tus beats, graba tus voces, mezcla con plugins integrados y carga tus VST3 y JSFX sin problema. Hecho en Santo Domingo, pa' que todo el que tenga una pauta la pueda grabar.
